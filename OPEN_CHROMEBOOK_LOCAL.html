CHROMEBOOK · OFFLINE CO-OP

ISOTOPE LOCAL

Play the downloaded build locally and connect two tabs directly in the browser. No GitHub site, Python server, or BAT file is needed for Chromebook mode.

Tip: after opening the game, use OPEN LOCAL CO-OP from the main menu whenever you need the local multiplayer setup again.

HOW TO PLAY LOCAL MULTIPLAYER

1
Open the gamePress OPEN ISOTOPE LOCAL. It opens the downloaded game in a new tab.
2
Open local co-opIn the game, press OPEN LOCAL CO-OP. Do this in both tabs.
3
Host the roomIn the first tab choose HOST, then GENERATE. Copy the connection code.
4
Join from the second tabChoose JOIN, paste the host code, then press GENERATE / ACCEPT.
5
Send the answer backCopy the answer from the JOIN tab and paste it into the HOST tab. Press APPLY ANSWER.
6
Start playingWait for CONNECTED. The second player can then join the same local co-op room.
Having trouble?
Keep both tabs open on the same Chromebook, paste the entire code without changing it, and allow the browser popup when the game opens the second tab.
